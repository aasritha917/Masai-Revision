1. What is HTTPS? How does it differ from HTTP?

HTTP
Sends data in plain text
Not secure
Anyone can read data

HTTPS
Secure version of HTTP
Data is encrypted
Uses SSL/TLS

Difference:
HTTPS is safe, HTTP is not safe

2. Explain SSL/TLS. What is the SSL handshake process?

SSL/TLS
Security protocols
Used to encrypt data between browser and server
SSL Handshake (simple steps):
Browser asks server for secure connection Server sends SSL certificate Browser verifies certificate Secure key is created
Encrypted communication starts

3. What is encryption? Explain symmetric vs asymmetric encryption.

Encryption
Converts data into secret form
Only authorized people can read it
Symmetric Encryption
Same key for encrypt & decrypt
Fast

Example: AES
Asymmetric Encryption
Two keys: public & private
More secure

Example: RSA

4. What are certificates? What is a Certificate Authority (CA)?

Certificates
Digital proof of website identity
Contains public key and website details
Certificate Authority (CA)
Trusted organization
Issues certificates
Example: Google, DigiCert, Let’s Encrypt

5. Difference between authentication and authorization?

Authentication
Who are you?
Login process
Authorization
What can you access?
Permissions after login

Example:
Login = Authentication
Access admin page = Authorization

6. Explain session-based authentication. How do sessions work?

Session-based authentication
Server stores user data
Client stores session ID in cookie
How it works:
User logs in
Server creates session
Session ID sent to browser
Browser sends session ID on every request
Server verifies session

7. What are cookies? Security attributes of cookies?

Cookies
Small data stored in browser
Used to store session info
Security attributes:
HttpOnly → JS can’t access cookie
Secure → Sent only over HTTPS
SameSite → Prevents CSRF attacks

8. What is token-based authentication? Difference from session-based?

Tken-based authentication
Server gives token (JWT)
Client stores token
Server does not store session
Difference:

Session-Based	Token-Based
Server stores session	No server storage
Uses cookies	Uses token
Stateful	Stateless
