1️.What is Express.js? Why use it over plain Node.js?

Express.js is a minimal and flexible web framework built on top of Node.js that simplifies building web servers and APIs.
Why Express over plain Node.js?
Easier routing (app.get, app.post)
Built-in middleware support
Cleaner request/response handling
Faster development
Better scalability & structure
Plain Node.js uses low-level APIs (http.createServer), Express abstracts them.

2️.What is middleware in Express? Explain the middleware chain.

Middleware is a function that:
Has access to req, res, and next
Runs before the final route handler
Can modify request/response or end the request

Middleware chain flow:
Request → Middleware 1 → Middleware 2 → Route → Response
Calling next() passes control to the next middleware.

4️.How does error handling work in Express?

Errors are passed using next(error)
Express looks for middleware with 4 parameters
Centralized error handling is best practice
app.use((err, req, res, next) => {
  res.status(500).send(err.message);
});

5️.Difference between app.use() and app.all()
app.use()	app.all()
Works for all HTTP methods	Works for all methods but specific route
Used for middleware	Used for route handling
Can be path-based	Always route-specific

6.Routing in Express & Route Parameters

Routing maps URL + HTTP method to handlers.
app.get("/users/:id", (req, res) => {
  res.send(req.params.id);
});

id is a route parameter, accessed via req.params.

7️.Route handlers vs Middleware
Middleware	Route Handler
Runs before route	Final response sender
Calls next()	Ends request
Reusable logic	Endpoint specific

8️.Handling file uploads in Express

Use multer middleware:
const multer = require("multer");
const upload = multer({ dest: "uploads/" });
app.post("/upload", upload.single("file"), (req, res) => {
  res.send("File uploaded");
});

9️.What is morgan? Logging strategies

Morgan is an HTTP request logger.
app.use(morgan("dev"));

Logging strategies:
Request logs (method, URL)
Error logs
Performance logs
Use Winston for production
