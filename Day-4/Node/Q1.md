1.What is CORS? Why does it exist?

CORS (Cross-Origin Resource Sharing) is a browser security rule. It controls which websites can access your API. It exists to stop malicious websites from reading data from another website without permission.

2.Explain the Same-Origin Policy

Same-Origin Policy allows a web page to access resources only from the same domain, protocol, and port. It prevents one website from stealing data from another website.

3.What are preflight requests? When do they occur?

Preflight requests are OPTIONS requests sent by the browser before the actual request. They happen when using non-simple methods like PUT, DELETE, custom headers, or JSON content type.

4.How do you configure CORS in Express?

In Express, CORS is configured using the cors package. You can allow specific origins, methods, and headers to control API access securely.

5.What is CSRF? How do you prevent it?

CSRF tricks a logged-in user into making unwanted requests. It is prevented using CSRF tokens, SameSite cookies, and checking request origins.

6.What is XSS? How do you prevent it?

XSS injects malicious scripts into web pages. It is prevented by escaping user input, using HTTPOnly cookies, and avoiding innerHTML.

7.What is SQL Injection? How do you prevent it?

SQL Injection allows attackers to run fake SQL queries. It is prevented using prepared statements, parameterized queries, and input validation.

8.What are rate limiting and throttling? Why important?

Rate limiting restricts the number of requests per user. Throttling slows down requests. They protect APIs from abuse, bots, and attacks.

9.What is the principle of least privilege?

It means users or systems should only get the minimum permissions needed. This reduces damage if an account is compromised.
