1️. What are the different types of queries in MongoDB?

Find queries → find(), findOne()
Conditional queries → using operators ($gt, $lt, $in)
Projection queries → selecting specific fields
Aggregation queries → aggregate() pipeline
Text search queries → $text
Geospatial queries
Update & delete queries

2️. What is projection in MongoDB?

Projection is used to select which fields to include or exclude in query results.
db.products.find({}, { name: 1, price: 1, _id: 0 })

Improves performance
Reduces network payload

3️.Comparison operators in MongoDB
Operator	Meaning
$eq	Equal
$ne	Not equal
$gt	Greater than
$gte	Greater than or equal
$lt	Less than
$lte	Less than or equal
$in	Matches any value in array
$nin	Not in array
{ price: { $gte: 500, $lte: 1000 } }

4️.Logical operators
Operator	Purpose
$and	All conditions true
$or	Any condition true
$not	Negation
$nor	None true
{
  $and: [
    { category: "Electronics" },
    { price: { $lt: 1000 } }
  ]
}

5️.Update operators
Operator	Use
$set	Update field
$unset	Remove field
$inc	Increment number
$push	Add to array
$pull	Remove from array
{ $inc: { stock: -1 } }

6️.What are indexes in MongoDB?

Indexes improve query performance by avoiding full collection scans.
Types of indexes
Single field index
Compound index
Text index
Multikey index
Geospatial index
TTL index
Hashed index

7️.Compound index & index order
db.products.createIndex({ category: 1, price: -1 })

Index Order Matters
{ category: 1, price: -1 } works for:
category
category + price
Does NOT work efficiently for price alone

8️.What is a covered query?

A covered query:
Uses only indexed fields
Returns results without touching documents
Faster
Lower memory usage

9️.How do you analyze query performance?

Using explain():
db.products.find({ category: "Electronics" }).explain("executionStats")

Key things to check:
COLLSCAN  (bad)
IXSCAN (good)
executionTimeMillis

10.What are TTL indexes?

TTL (Time-To-Live) indexes automatically delete documents after a specified time.

db.sessions.createIndex(
  { createdAt: 1 },
  { expireAfterSeconds: 3600 }
)

Used for:
Sessions
OTPs
Logs
Temporary data
