1️.What is the aggregation framework in MongoDB?

The aggregation framework processes data through multiple stages, transforming documents into aggregated results (like SQL GROUP BY, JOIN, SUM, etc.).

Used for analytics
More powerful than find()
Pipeline-based processing

2️. Explain aggregation pipeline stages
Stage	Purpose
$match	Filter documents
$group	Group & aggregate data
$project	Shape output
$sort	Sort results
$limit	Limit number of documents
db.orders.aggregate([
  { $match: { status: "completed" } },
  { $group: { _id: "$userId", total: { $sum: "$amount" } } }
])

3️. What is $lookup?

$lookup performs a join between collections.
{
  $lookup: {
    from: "users",
    localField: "userId",
    foreignField: "_id",
    as: "user"
  }
}

MongoDB equivalent of JOIN

4️. What is $unwind?

Breaks an array field into multiple documents.
{ $unwind: "$items" }
Used when:
Aggregating arrays
One-to-many relationships

5️.What are aggregation expressions & operators?

Expressions perform calculations:
$sum
$Avg
$min
$max
$concat
$cond
{ $sum: "$price" }

6️.One-to-Many relationships in MongoDB

Handled using:
Embedded documents (preferred for small data)
References + $lookup (large data)

7️.Many-to-Many relationships

Use references on both sides:
User ↔ Products
Students ↔ Courses
Often resolved using $lookup

8️. Data modeling & 6 rules of thumb

MongoDB favors application-driven design.

Rules of Thumb:
Embed when data is accessed together
Reference when data grows unbounded
void deep nesting
Duplicate data when reads are frequent
Design for queries, not normalization
Optimize for performance, not storage

9️.What are atomic operations?

Operations that complete entirely or not at all.
Examples
$set
$inc
$push
Atomic at document level

10.What is a transaction?

A transaction allows multiple operations to succeed or fail together.
Use when:
Updating multiple collections
Financial operations
Strong consistency required
session.startTransaction();
