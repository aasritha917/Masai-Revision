1.What is MongoDB? How is it different from relational databases?

MongoDB is a NoSQL, document-oriented database developed by MongoDB.

Differences from Relational Databases (MySQL, PostgreSQL)
MongoDB	Relational DB
Stores data as documents	Stores data as tables
Schema-flexible	Fixed schema
JSON-like format	Rows & columns
Scales horizontally	Scales vertically
Faster for large unstructured data	Strong for complex joins

2️.What are collections and documents?
Document → A single record (like a row)
Collection → Group of documents (like a table)
Example document:

{
  "name": "iPhone 15",
  "price": 80000,
  "category": "Electronics"
}

3️.What is BSON? How is it different from JSON?

BSON = Binary JSON
MongoDB stores data internally in BSON
BSON vs JSON
BSON	JSON
Binary format	Text format
Faster to parse	Slower
Supports more data types (Date, ObjectId)	Limited types

4️.Explain MongoDB document structure. What is _id?
Each MongoDB document:
Is a key–value pair
Has a unique _id field

{
  "_id": ObjectId("64fabc..."),
  "name": "Laptop",
  "price": 60000
}
_id
Primary key
Automatically generated
Must be unique

6️.Embedded documents vs References
Embedded Document
{
  "orderId": 1,
  "customer": {
    "name": "Aasritha",
    "phone": "9999999999"
  }
}

Reference
{
  "orderId": 1,
  "customerId": "abc123"
}

7️.When to embed vs reference?
Embed when:
Data is used together
One-to-few relationship
Need fast read
Reference when:
Large data
Frequently changing data
One-to-many / many-to-many

8️.Advantages & Disadvantages of MongoDB
Advantages

Flexible schema
High performance
Easy horizontal scaling
JSON-like structure

Disadvantages
No joins like SQL
Data duplication risk
Not ideal for complex transactions

9️.Schema design in MongoDB – Is it schema-less?

 MongoDB is schema-flexible, not schema-less
Documents in same collection can have different fields
Best practice: follow a logical schema design
Schema validation can be enforced

10.What is the Aggregation Pipeline?

Used to process data step-by-step

Example stages:
$match → filter
$group → grouping
$sort
$project
$limit
Example:

db.products.aggregate([
  { $match: { category: "Electronics" } },
  { $group: { _id: "$category", total: { $sum: "$price" } } }
])
