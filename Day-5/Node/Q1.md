1.What is Node.js? How does it differ from browser JavaScript?

Node.js is a runtime environment that allows JavaScript to run outside the browser, mainly on servers. Browser JavaScript is used for UI and DOM manipulation, while Node.js is used for backend tasks like file handling, APIs, and databases. Node.js has access to system resources (files, OS), but browser JavaScript does not.

2️.What is the event loop in Node.js? How does it work?

The event loop is a mechanism that handles asynchronous operations in Node.js. It continuously checks the call stack, callback queue, and other queues. If the call stack is empty, it pushes queued callbacks for execution. This allows Node.js to handle many tasks efficiently using a single thread.

3️.What is non-blocking I/O? How does Node.js achieve it?

Non-blocking I/O means operations like file reading or network requests do not block the main thread. Node.js achieves this by using asynchronous APIs and the event loop. Long-running tasks are handled in the background, and callbacks/promises are executed once the task is complete.

4️.Difference between synchronous and asynchronous code

Synchronous code blocks execution until a task is finished, meaning the next line waits. Asynchronous code does not block execution; tasks run in the background and return results later using callbacks, promises, or async/await. Node.js prefers asynchronous code for better performance.

5️.What are callbacks? What is callback hell?

Callbacks are functions passed as arguments to be executed later. Callback hell happens when callbacks are nested deeply, making code hard to read and maintain. It often occurs in asynchronous operations like multiple API calls inside each other.

6️.What are Promises? How do they solve callback hell?

Promises represent a value that will be available in the future. They use .then() and .catch() instead of nested callbacks. Promises flatten the code structure, improve readability, and make error handling easier compared to callback-based code.

7️.What is async/await? How does it work internally?

Async/await is syntax built on top of promises. async functions always return a promise, and await pauses execution until the promise resolves. Internally, it uses promises but makes asynchronous code look like synchronous code, improving readability.

8️.Difference between process.nextTick() and setImmediate()

process.nextTick() executes a callback immediately after the current operation completes, before the event loop continues. setImmediate() executes callbacks in the next event loop iteration. nextTick has higher priority and can block the event loop if overused.

10.What is the Buffer class in Node.js?

Buffer is used to handle binary data in Node.js. Since JavaScript doesn’t support binary data directly, Buffer allows working with raw data like files, images, and streams. It is commonly used when reading files or receiving network data.
